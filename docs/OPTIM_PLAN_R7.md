# Rift Forge R7：波間戰鬥委託

本輪從現有 R6 隔離副本施工；原始碼正本、舊 APK、舊證據、玩家儲存不寫入。版本目標 1.3.1／Android code 5。

新增有限且可選的戰鬥目標，保留既有多次鍛造、經濟成本、傷害、敵人、波數、路線、初鍛、碰撞及命中時序。每次 Forge 可循環選擇下一波的「不接／相位反擊／終結連擊／鍛印命中」，開啟下一波後鎖定；不接與未達成皆無懲罰。

| 委託 | 真正達成條件 | 本波結束且碎片收齊後一次獎勵 |
|---|---|---|
| 相位反擊 | Counter 在原命中幀至少命中一個敵人 | 4 碎片 |
| 終結連擊 | 兩次不同的 Finisher 分別在命中幀命中敵人 | 5 碎片 |
| 鍛印命中 | 同一波兩次不同的鍛印實際命中事件；不要求同一爆發，不重算同一敵人同次爆發 | 6 碎片 |

最後一項按既有 DetonateImprints 的真實傷害命中認列；只留下印、引爆空地、按斬擊或取消施放均不認列。每波至多結算一次；Forge 換選委託不發獎，敗北不發獎。Combat checkpoint 會重開整波，因此委託進度也隨整波重新計算，不保留可重刷的半波累積。Forge checkpoint 保存下一波選擇及已結算回報；舊 schema1 存檔無委託時照常可讀。

## 八大面向與驗收邊界

| 面向 | 本輪處理與證據 |
|---|---|
| 美術 | 沿用 R6 資產，不產新模型／圖片；不把既有 fallback 或幾何場景升格為完成美術。既有正式模型、三視圖與整體美術缺口仍列未完成。 |
| 按鈕 | 新委託選擇與既有鍛造、下一波、返回在 320×568、390×844、844×390、1280×640 的安全區內命中至少44px，互不重疊、無捲動依賴。 |
| 選單 | 僅在原 Forge 加一列可循環選擇及規則文字；所有返回／續玩語意保留，Combat 沒有新遮擋面板。 |
| 人物 | 不換臉、不變更身份、比例與剪影；既有角色來源與64px人工驗收不因本輪自動通過。 |
| 地圖 | 不新增或改裝場景，保留現有3D位置／碰撞。正式主題場景與整款視覺仍未取得9分。 |
| 技能 | 僅觀察既有反擊、終結技與鍛印真實命中；不改傷害、命中幀、冷卻、能量、敵人或生成規則。空揮、取消、空印零進度。 |
| 角色樣子 | 無新角色與素材；不以本輪邏輯測試聲稱亮度／飽和度／三視圖已通過。 |
| 動作 | 沿用既有表演及命中流程，不用位移／旋轉假造新動畫；新測試確認只在真實 impact／remote imprint hit 事件增加進度。 |

## 必要檢查

1. 純規則：None、三種目標、空揮零進度、上限、phase guard、未完成與敗北零獎、一次性結算、舊存檔、Forge選擇保存、Combat整波重開清零。
2. Unity EditMode／PlayMode 既有完整套件加有意義新測試；檢查真實 ResolveStrike／DetonateImprints 到規則的接線及 UI raycast／文字／44px／安全區。
3. 全部 Unity 僅 hidden、BelowNormal、batchmode、nographics，必有 Null Device；H3 GPU 優先，本輪不開硬體渲染、不執行本機AI、不啟動瀏覽器。
4. 通過後以既有 RiftDevelopmentBuild.Android 建 development APK，完整 SDK/NDK/JDK、唯一輸出路徑，讀回 package/version/code/ARM64/SDK/debug signature/CRC；這不是裝置遊玩或商店接受。
5. source manifest、before/after、秘密掃描（僅輸出數量與路徑）、原始來源保護、來源／輸出包逐檔SHA；現有失敗證據保留。不重跑未修改的已通過大型流程。
6. 仍未完成：真正渲染的before/after及裝置畫面、連續全程、真人／實機、Mac／iOS、乾淨機桌機／手機p95、GPT＋Claude獨立整款9分。Null graphics絕不冒稱畫面／效能通過。
7. 僅本機隔離候選，不做正本CAS、commit、push、簽正式key、上架／發布。此限制承接目前本機範圍；全案13筆／8組仍未完成。
